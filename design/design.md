# Kimi 倒计时 — 初版视觉设计存档

> 本文档保留 Kimi 生成的初版设计方向，仅作历史参考；当前 0.2.x 界面已重构为 Moment 主视觉与时间线结构，实际实现以 `src/` 为准。

## 设计方向

现代、温暖、精致。采用低饱和度暖色系 + 毛玻璃效果，营造桌面「温暖陪伴」的氛围感。

## 色彩系统

### 主色调（暖色方向）
| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | `#7B61FF` | 品牌色、按钮、强调 |
| 辅色 | `#FF6B6B` | 点缀、倒计时结束状态 |
| 强调色 | `#FFB347` | 暖色点缀、悬停效果 |
| 成功色 | `#4ECDC4` | 完成状态 |

### 背景色
| 模式 | 色值 | 用途 |
|------|------|------|
| 浅色背景 | `#F8F6F3` | 主界面背景（温暖米白） |
| 深色背景 | `#1A1A2E` | 深色模式背景 |
| 卡片浅色 | `rgba(255,255,255,0.8)` | 卡片背景（毛玻璃） |
| 卡片深色 | `rgba(30,30,46,0.8)` | 深色模式卡片 |

### 文字色
| 角色 | 浅色模式 | 深色模式 |
|------|----------|----------|
| 主文字 | `#2D3436` | `#F8F9FA` |
| 次文字 | `#636E72` | `#ADB5BD` |
| 辅助文字 | `#B2BEC3` | `#6C757D` |

## 字体

- 主字体：`-apple-system, 'PingFang SC', 'Segoe UI', sans-serif`
- 倒计时数字：`'SF Mono', 'JetBrains Mono', monospace`（等宽，翻牌效果）
- 标题字重：600-700
- 正文字重：400-500

## 圆角系统

| 层级 | 圆角 |
|------|------|
| 小元素（按钮、标签） | 10px |
| 卡片 | 20px |
| 模态框 | 24px |
| 悬浮窗整体 | 16px |

## 动画系统

| 动画 | 时长 | 缓动 |
|------|------|------|
| 卡片入场 | 400ms | cubic-bezier(0.34, 1.56, 0.64, 1) |
| 卡片悬停 | 200ms | ease-out |
| 模态框 | 300ms | cubic-bezier(0.16, 1, 0.3, 1) |
| 数字变化 | 300ms | ease-in-out |
| 按钮反馈 | 150ms | ease |
| 删除确认 | 200ms | ease-in-out |

## 核心组件设计

### 1. CountdownCard（倒计时卡片）

```
┌────────────────────────────────────┐
│  🔴 事件名称（小字，带颜色圆点）     │
│                                     │
│   ┌──┐ ┌──┐ ┌──┐ ┌──┐              │
│   │01│ │23│ │45│ │67│  ← 翻牌数字   │
│   │天│ │时│ │分│ │秒│              │
│   └──┘ └──┘ └──┘ └──┘              │
│                                     │
│   ████████████░░░░░░  进度条        │
│   目标: 2025年12月25日              │
│                                     │
│  [编辑] [删除]                       │
└────────────────────────────────────┘
```

- 背景：毛玻璃 rgba(255,255,255,0.75) + backdrop-blur(20px)
- 边框：1px solid rgba(255,255,255,0.3)
- 翻牌数字：等宽字体，卡片式翻转动画
- 进度条：事件颜色渐变，底部圆角

### 2. 主窗口框架

- 自定义标题栏：毛玻璃效果，左侧 Logo + 标题，右侧控制按钮（置顶/最小化/关闭）
- 底部工具栏：毛玻璃，左侧导入/导出，中间事件计数，右侧添加按钮（圆形悬浮感）
- 整体圆角：16px
- 无系统边框，自定义控制按钮

### 3. AddEventModal（添加模态框）

- 背景遮罩：rgba(0,0,0,0.4) + backdrop-blur(10px)
- 模态框：毛玻璃背景，大圆角，精致的表单控件
- 颜色选择器：圆形色块，选中时放大 + 阴影
- 时间选择器：自定义样式
- 模板选择：卡片式网格，悬停放大

### 4. EmptyState（空状态）

- 中央大图标：沙漏或时钟的 SVG 动画
- 文字：温暖色调，友好的引导语
- 添加按钮：渐变背景，吸引人的 CTA

## 翻牌数字效果

```css
.flip-card {
  perspective: 400px;
}
.flip-card-inner {
  transition: transform 0.6s;
  transform-style: preserve-3d;
}
.flip-card.flipped .flip-card-inner {
  transform: rotateX(-180deg);
}
```
